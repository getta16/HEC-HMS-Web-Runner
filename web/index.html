HEC-HMS Web Runner

อ่านไฟล์โปรเจกต์ HEC-HMS (.hms, .basin, .met, .gage, .control, .run, .pdata และ .dss) แล้วคำนวณน้ำท่าในเบราว์เซอร์ ไฟล์ทั้งหมดอ่านในเครื่องของคุณ ไม่มีการส่งขึ้นเซิร์ฟเวอร์ เริ่มต้นเปิดโปรเจกต์ Vara1 ไว้ให้ ถ้าจะใช้โปรเจกต์อื่นให้อัปโหลดทั้งโฟลเดอร์หรือลากไฟล์มาวางในหน้านี้

⚠ผลเป็นค่าประมาณ ไม่ใช่ HEC-HMS ตัวจริง ตัวคำนวณเขียนขึ้นใหม่ด้วย JavaScript ตามวิธีของ HEC-HMS เมื่อ time interval เท่ากับช่วงของ Unit Hydrograph ผลตรงกับ HEC-HMS แต่ถ้า interval ละเอียดกว่านั้น (เช่น 1 นาที) peak จะต่างราว 1% เพราะวิธีแปลง UH ต่างกัน ถ้ามีไฟล์ RUN_*.results หน้านี้จะเทียบผลกับ HEC-HMS ให้ดู
