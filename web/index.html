Castro Valley Runoff Model

จำลองน้ำท่าจากพายุวันที่ 16 มกราคม 1973 บนลุ่มน้ำ Castro Valley (5.51 ตร.ไมล์) ในเบราว์เซอร์ อ่านไฟล์ .basin / .met / .gage / .control ในรูปแบบของ HEC-HMS แล้วคำนวณ loss → transform → baseflow → routing ทีละ element เปรียบเทียบสภาพปัจจุบันกับสภาพอนาคต

⚠ไฟล์อินพุตเป็นไฟล์จำลอง (mock) ไฟล์ .basin, .met, .gage และ .control ไม่ได้มาพร้อมโปรเจกต์ จึงสร้างขึ้นใหม่ ส่วน Future ถูกปรับค่าให้ใกล้ผลใน RUN_Future.results (ดูคอลัมน์ “อ้างอิง” ในตาราง) ส่วน Existing ตั้งค่าขึ้นเองเพื่อสาธิต ไม่ใช่ข้อมูลจริงของลุ่มน้ำ

Loss · Initial + Constantพื้นที่ซึมน้ำได้เสียน้ำช่วงแรกตาม Initial Loss แล้วเสียต่อเนื่องตาม Constant Rate ส่วนพื้นที่ทึบน้ำ (% impervious) กลายเป็นน้ำท่าทั้งหมด

Baseflow · Recessionน้ำท่าเริ่มต้น = อัตราต่อพื้นที่ × พื้นที่ ลดลงด้วย Recession Factor (ต่อวัน) เมื่อน้ำลดต่ำกว่า threshold × peak จะลดแบบ recession
